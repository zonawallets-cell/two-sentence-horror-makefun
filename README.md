A one-line program that writes a two-sentence horror story: a sleep-study report whose count is off by one — and the extra breath belongs to something else in the room. Pure Python standard library, no dependencies.

> The sleep study said I stop breathing forty times a night. Last night it recorded forty-one, and one of them wasn't mine.

## Run it

```sh
python3 main.py
```
